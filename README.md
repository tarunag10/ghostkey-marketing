# GhostKey Marketing

GTM marketing website for GhostKey, a Safari extension that helps reduce intrusive sign-in prompts and restore page usability.

## Live Links

- Download: Add the approved App Store URL in `site.config.json` after the app is available.
- Marketing Site: https://ghostkey-marketing.vercel.app
- Privacy Policy: https://tarunag10.github.io/GhostKey/privacy-policy.html
- Support: https://tarunag10.github.io/GhostKey/support.html

## Local Development

```bash
npm run dev
```

Open http://localhost:4173.

## Validation

```bash
npm run build
```

The build validates required pages, exact support/privacy URLs, and Apple-safe copy constraints.
