# GhostKey Privacy Metadata

Tracking: No

Data Collection: Data Not Collected

GhostKey does not collect personal data. It stores extension preferences locally in browser storage, including enabled state, aggressive mode, debug mode, disabled sites, and allowlisted hosts. These settings remain on the user's device and are not transmitted to developer servers.

GhostKey uses page access only to detect and suppress intrusive overlays directly in Safari. Page content, URLs, browsing history, account information, payment information, and form contents are not sent to the developer. The extension does not include analytics, advertising SDKs, tracking SDKs, remote API calls, account creation, or server-side storage.
